# دفتر حساب موبایل علی

نسخه GitHub Pages برای مدیریت مشتری، بدهی و اقساط.

امکانات:
- نمایش تاریخ‌ها و رسیدها با تقویم شمسی
- ثبت مشتری و شماره تماس
- ثبت بدهی/فاکتور
- ثبت اقساط و پرداخت‌های چندمرحله‌ای
- محاسبه خودکار مانده
- داشبورد و جستجو
- رسید تصویری PNG با لوگوی موبایل علی
- درج نام فروشگاه، آدرس، شماره‌های تماس و آقای خزیمه در رسید
- دانلود و اشتراک‌گذاری رسید تصویر
- ارسال متن مانده با SMS
- دانلود پشتیبان JSON و بازیابی آن
- ذخیره محلی در مرورگر
